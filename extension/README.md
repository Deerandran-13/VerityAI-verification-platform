# VerityAI Browser Extension (Manifest V3)

The VerityAI browser extension integrates web browsing with the VerityAI verification engine.

## Installation in Chrome / Edge / Brave

1. Open your browser and navigate to `chrome://extensions` (or `edge://extensions`).
2. Toggle on **Developer mode** in the top-right corner.
3. Click **Load unpacked**.
4. Select this directory (`VerifyAI/extension`).
5. Pin the **VerityAI** extension to your toolbar.

## Features
- **Right-Click Fact Check**: Highlight any text, right-click, and select *"Verify with VerityAI"*.
- **Instant Pop-up Audit**: Open the extension popup to paste or review text.
- **Direct Live Results**: Shows claim status badges, overall freshness %, confidence %, and links directly to the full interactive Verification Report in VerityAI (`http://localhost:5173/results?id=...`).
